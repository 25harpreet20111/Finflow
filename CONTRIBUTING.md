# Contributing to FinFlow

Thank you for your interest in contributing to FinFlow!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test the application locally.
5. Commit your changes with a clear message.
6. Push your branch.
7. Create a Pull Request.

## Development Guidelines

- Write clean and readable code.
- Use meaningful variable and function names.
- Test new features before submitting changes.
- Keep commits focused and descriptive.
- Do not commit `.env` files or sensitive credentials.

## Reporting Issues

If you find a bug or have a feature suggestion, please create an issue with enough information to reproduce or understand the problem.

Thank you for helping improve FinFlow!
