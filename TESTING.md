\# FinFlow Testing



\## Overview



FinFlow uses \*\*Vitest\*\* for automated testing of frontend utility functions.



The current test suite focuses on the SMS parsing functionality used to extract financial information from bank SMS messages.



\## Testing Technology



\- \*\*Test Framework:\*\* Vitest

\- \*\*Language:\*\* TypeScript

\- \*\*Application:\*\* React + TypeScript

\- \*\*Test Location:\*\* `client/src/utils/`
