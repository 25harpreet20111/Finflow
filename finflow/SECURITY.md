# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in FinFlow, please report it privately rather than publicly posting sensitive details.

When reporting an issue, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The affected component
- Any relevant screenshots or logs

## Security Guidelines

- Never commit `.env` files or private credentials.
- Keep JWT secrets secure.
- Use environment variables for sensitive configuration.
- Do not share database credentials publicly.
- Keep project dependencies updated.
- Validate and sanitize user input.

Thank you for helping keep FinFlow secure.
